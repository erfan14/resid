# رسید | نسخهٔ نمایشی

نسخهٔ نمایشی «رسید» برای چالش ریشه‌یابی (AI Solo Founder Camp | دیجی‌نکست).

«رسید» برای فروشنده‌های خانگی اینستاگرام است: سفارش در لحظهٔ پرداخت ثبت می‌شود، تا وقتی ارسال نشده هر صبح به فروشنده یادآوری می‌شود، و مشتری با شماره و آدرسش در فهرستی ذخیره می‌شود.

- کل برنامه یک فایل `index.html` است و سرور لازم ندارد.
- درگاه پرداخت، پیامک و زمان شبیه‌سازی شده‌اند.
- داده‌ها فقط در مرورگر هر بازدیدکننده نگه داشته می‌شود.
